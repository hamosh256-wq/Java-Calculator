# ☕ Java Scientific Calculator

A scientific calculator built with **Java**, **Swing**, and **Object-Oriented Programming (OOP)**.

## ✨ Features

- Basic arithmetic: addition, subtraction, multiplication, and division.
- Advanced operations: powers, square roots, and modulo.
- Trigonometric functions: `sin`, `cos`, and `tan` (degrees).
- Common logarithm (`log₁₀`).
- Mathematical constants: π.
- Memory functions: `MC`, `MR`, `M+`, and `M-`.
- Calculation history.
- Dark-themed graphical user interface.
- Error handling for invalid input.

## 🎮 Controls

| Button | Function |
|---|---|
| `+`, `-`, `*`, `/` | Basic arithmetic |
| `^` | Exponentiation |
| `√` | Square root |
| `1/x` | Reciprocal |
| `%` | Modulo |
| `sin`, `cos`, `tan` | Trigonometric functions |
| `log` | Base-10 logarithm |
| `π` | Insert pi |
| `C` | Clear current calculation |
| `DEL` | Delete the last character |
| `MC`, `MR`, `M+`, `M-` | Memory operations |

## 🛠️ Built With

- **Java**
- **Java Swing** — graphical user interface
- **AWT** — layout and event handling
- **OOP** — separating calculation logic from the GUI

## 🚀 Getting Started

### Requirements

- Java Development Kit (JDK)

### Run the Application

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Compile the source file:

   ```bash
   javac Main.java
   ```

4. Run the application:

   ```bash
   java Main
   ```
